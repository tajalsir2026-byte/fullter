# حسابات الذهب — Gold Accounts

تطبيق **Flutter** لمحاسبة محلات وتجارة الذهب، بالعربية وبنظام الوزن المحلي (**جرام . حبة . جزء**).
يعمل بالكامل بدون إنترنت، والبيانات محفوظة داخل الجهاز.

<div dir="rtl">

## الشاشات

| الشاشة | الوظيفة |
|---|---|
| **الرئيسية** | ملخّص شامل: الربح الصافي، رصيد المخزون وقيمته، النقد التقديري، الديون المستحقة |
| **المشتريات** | تسجيل المشتريات، المتبقي للبائع، سجل الدفعات، الوزن المباع من كل مشترى |
| **المبيعات** | تسجيل المبيعات مع **ربطها بمشترى معيّن** لخصم المخزون وحساب التكلفة تلقائياً |
| **المنصرفات اليومية** | مصروفات عامة (تُخصم من الربح) ومصروفات خاصة (تُخصم من حساب الشريك) |
| **رأس المال والشركاء** | نسبة كل شريك، حصته من الربح، مصروفاته الخاصة، وصافي مستحقاته |
| **الإعدادات** | كلمة السر، القفل التلقائي، الوضع الداكن، النسخ الاحتياطي |

## المعادلات المحاسبية المستخدمة

```
الوزن              = جرام×100 + حبة×10 + جزء     (أعداد صحيحة، بلا كسور عشرية)
رصيد المخزون       = وزن المشتريات − وزن المبيعات
متوسط تكلفة الجرام = إجمالي المشتريات ÷ وزنها
ربح المبيعات       = مبلغ البيع − التكلفة
الربح الصافي       = ربح المبيعات − المنصرفات العامة
نسبة الشريك        = رأس ماله ÷ إجمالي رأس المال
حصته من الربح      = نسبته × الربح الصافي
صافي مستحقاته      = رأس ماله + حصته من الربح − مصروفاته الخاصة
النقد التقديري     = رأس المال + المبيعات − المدفوع للبائعين − المنصرفات
```

## الحماية

- كلمة السر تُخزَّن كبصمة **SHA-256 مع ملح عشوائي** (لا تُحفظ كنص صريح).
- قفل تلقائي عند الخروج من التطبيق (المدة قابلة للضبط).
- تأخير تصاعدي بعد 5 محاولات خاطئة.
- `allowBackup=false` — لا تُرفع بيانات التطبيق تلقائياً لسحابة جوجل.

> ⚠️ لا يمكن استرجاع كلمة السر إذا نسيتها. خُذ نسخة احتياطية دائماً.

## النسخ الاحتياطي

من **الإعدادات ← النسخ الاحتياطي**:

1. **إنشاء نسخة الآن** — ملف JSON داخل:
   `Android/data/com.tajalsir.gold/files/backups/`
2. **النسخ المحفوظة** — عرض واستعادة وحذف النسخ السابقة.
3. **نسخ البيانات كنص** — لإرسالها عبر الواتساب أو الإيميل، والاستعادة بلصقها.

## المزامنة بين الأجهزة (اختيارية)

يمكن ربط أكثر من جهاز بنفس البيانات عبر Supabase (مجاناً):

1. أنشئ مشروعاً على supabase.com ونفّذ سكربت SQL الموجود في دليل الإعداد
2. ضع `Project URL` و `anon key` في `lib/core/cloud_config.dart`
3. من التطبيق: الإعدادات ← المزامنة بين الأجهزة ← إنشاء حساب / تسجيل دخول

**كيف تعمل:** التطبيق يبقى يعمل أوفلاين بالكامل. عند توفر الإنترنت يسحب نسخة
السحابة ويدمجها مع المحلية (الأحدث يفوز لكل سجل، والحذف يُنقل عبر علامات حذف)
ثم يرفع الناتج. إذا تُركت الإعدادات فارغة، تختفي المزامنة ويعمل التطبيق كالمعتاد.

## البناء

### محلياً

```bash
flutter pub get
flutter analyze
flutter test
flutter run                 # تجربة على جهاز/محاكي
flutter build apk --release # ملف APK
```

### عبر Codemagic

ادفع الكود إلى GitHub — ملف `codemagic.yaml` يشغّل: `pub get` ← `analyze` ← `test` ← بناء APK و AAB.

### التوقيع للنشر على Google Play

```bash
keytool -genkey -v -keystore ~/gold-release.jks \
  -keyalg RSA -keysize 2048 -validity 10000 -alias gold
```

ثم أنشئ `android/key.properties` (**لا ترفعه على GitHub**):

```properties
storePassword=كلمة_سر_المخزن
keyPassword=كلمة_سر_المفتاح
keyAlias=gold
storeFile=/home/USER/gold-release.jks
```

إذا لم يوجد هذا الملف، يبني المشروع بمفتاح الـ debug (للتجربة فقط، لا يصلح للنشر).

## تغيير الهوية

| ما تريد تغييره | المكان |
|---|---|
| اسم التطبيق الظاهر | `android/app/src/main/AndroidManifest.xml` ← `android:label` و `lib/core/constants.dart` ← `kAppName` |
| معرّف التطبيق | `android/app/build.gradle` ← `applicationId` و `namespace` + مجلد `kotlin/com/tajalsir/gold` |
| الأيقونة | `assets/icon_source.png` ثم توليد مقاسات `mipmap-*` |
| العملة | `lib/core/constants.dart` ← `kCurrency` |
